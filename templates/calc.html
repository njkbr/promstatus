Раздел XVII ПП №719 · ред. от 15.10.2026

Калькулятор баллов для лёгкой промышленности

Ориентировочный расчёт: проходит ли продукция минимальный порог для акта экспертизы ТПП.

усл.

Для материалов укажите долю российских позиций в изделии по номенклатуре составляющих, например 2 из 4 видов фурнитуры = 50%.

Набрано баллов 0 из 0

Проверить с экспертом

Расчёт ориентировочный. Окончательное количество баллов определяет ТПП по документам и итогам выездной проверки. «Российскость» материалов оценивается по правилам определения страны происхождения СНГ и подтверждается документами поставщика: актом экспертизы, сертификатом СТ-1 или реестровой записью.

Если продукции нет в разделе XVII, баллы не нужны: подтверждение идёт через сертификат СТ-1 по правилам происхождения СНГ. Для одежды, обуви, головных уборов, сумок, домашнего текстиля и меховых изделий действует общий критерий: изделие должно сменить товарную позицию ТН ВЭД по первым четырём знакам по сравнению с материалами (например, ткань → костюм). Глажка, упаковка, простая сборка и комплектование наборов не засчитываются. Особые условия есть для кожи, собранных меховых шкурок, комбинированных нитей, ковров и ковриков.

Подробнее о пути через СТ-1 – на странице «Под ключ: СТ-1». Требования для групп из ПП №1026 действуют с 01.01.2027, подробнее в разборе.
