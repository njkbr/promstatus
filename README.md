# promstatus.ru

Исходники сайта promstatus.ru.

- `content/home.toml` — тексты главной страницы
- `content/pages/` — страницы (услуги, документы, политика)
- `content/articles/` — статьи
- `site.toml` — контакты и настройки (анкета, Метрика, реквизиты)

После изменения файла в ветке `main` сайт пересобирается автоматически и появляется на promstatus.ru примерно через 5 минут.
